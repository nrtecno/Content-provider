# EARNING WITH VIDEOS 💎

**EARNING WITH VIDEOS** एक एडवांस टेलीग्राम बॉट और मिनी ऐप (Mini App) सिस्टम है, जिसे खास तौर पर वीडियो शेयरिंग और ऐड नेटवर्क्स (Monetag और Adsgram) के ज़रिए कमाई करने के लिए डिज़ाइन किया गया है। यह सिस्टम वीडियो को सुरक्षित रूप से स्टोर करता है, यूज़र्स को ऐड्स के ज़रिए वीडियो उपलब्ध कराता है, और 10 मिनट बाद वीडियो को अपने आप डिलीट कर देता है।

---

## ⚙️ यह कैसे काम करता है? (How it Works)

1. **वीडियो अपलोड**: एडमिन (या अप्रूव्ड सेंडर) बॉट को एक फोटो (थंबनेल) और वीडियो एक साथ (एल्बम में) भेजता है।
2. **क्लाउड स्टोरेज**: बॉट उस वीडियो और फोटो को एक प्राइवेट "Storage Channel" में बैकअप के तौर पर सेव कर लेता है, ताकि आपकी चैट से वीडियो डिलीट होने पर भी वो कभी न मरे।
3. **चैनल पोस्ट**: बॉट उस थंबनेल को आपके "Destination Channel" में एक **"👉 Play Online Free"** बटन के साथ पोस्ट करता है।
4. **मिनी ऐप (Mini App)**: जब कोई यूज़र उस बटन पर क्लिक करता है, तो एक मिनी ऐप खुलता है जहाँ उसे **Monetag (Player 1)** और **Adsgram (Player 2)** के ऐड्स दिखाए जाते हैं।
5. **वीडियो डिलीवरी**: ऐड पूरा होने के बाद, यूज़र बॉट पर रीडायरेक्ट होता है और बॉट उसे वह वीडियो भेज देता है। (यह वीडियो 10 मिनट बाद अपने आप यूज़र के चैट से डिलीट हो जाती है)।

## 🚀 सेटअप गाइड (Step-by-Step Setup Guide)

इस बॉट को चलाने के लिए आपको नीचे दिए गए स्टेप्स को फॉलो करना होगा:

### 🔹 चरण 1: इस रिपॉजिटरी का लिंक कॉपी करें
1. इस GitHub पेज पर सबसे ऊपर हरे रंग का **"<> Code"** बटन दबाएं।
2. वहाँ से **HTTPS** वाला लिंक कॉपी कर लें (जैसे: `https://github.com/username/repo-name.git`)। यही लिंक हम Render पर इस्तेमाल करेंगे।

### 🔹 चरण 2: टेलीग्राम बॉट बनाएं (BotFather)
1. टेलीग्राम पर **@BotFather** को खोलें।
2. `/newbot` कमांड भेजें और अपने बॉट का नाम और यूज़रनेम सेट करें।
3. आपको एक **BOT_TOKEN** मिलेगा, इसे सुरक्षित रखें।

### 🔹 चरण 3: मिनी ऐप (Mini App) बनाएं
1. **@BotFather** में `/newapp` कमांड भेजें।
2. अपना बॉट सेलेक्ट करें।
3. मिनी ऐप का Title (जैसे- Video Player) और Description डालें।
4. एक 640x360 पिक्सल का फोटो अपलोड करें।
5. जब Web App URL मांगा जाए, तो अभी के लिए कोई भी डमी URL डाल दें (बाद में इसे Render URL से बदलेंगे)।
6. अब एक Short Name डालें (जैसे: `Wach` या `Play`)। **इसे याद रखें, आगे काम आएगा।**

### 🔹 चरण 4: डोमेन सेट करें
मिनी ऐप को टेलीग्राम के अंदर चलाने के लिए डोमेन वेरिफाई करना ज़रूरी है:
1. **@BotFather** में `/setdomain` कमांड भेजें।
2. अपना बॉट सेलेक्ट करें।
3. अपना Render डोमेन डालें (जैसे: `your-app.onrender.com` - इसे बाद में बदलेंगे)।

### 🔹 चरण 5: चैनल्स की व्यवस्था करें
आपको 2 चैनल बनाने होंगे:
1. **Destination Channel**: जहाँ आपकी वीडियो की पोस्ट यूज़र्स को दिखेगी।
2. **Storage Channel**: एक प्राइवेट चैनल जहाँ वीडियोज़ का बैकअप रहेगा।
3. **ध्यान दें**: अपने बॉट को दोनों चैनल्स में **Admin** बनाएं और "Post Messages" की परमिशन दें।

### 🔹 चरण 6: Render पर डिप्लॉय करें (Public Repository का उपयोग करके)
1. [Render.com](https://render.com) पर जाएं और अपना अकाउंट बनाएं।
2. **New +** पर क्लिक करें और **Web Service** चुनें।
3. नीचे दिए गए विकल्पों में से **"Public Git repository"** चुनें।
4. वहाँ अपना वह **GitHub रिपॉजिटरी लिंक** पेस्ट करें जो आपने चरण 1 में कॉपी किया था।
5. **Build Command** में डालें: `pip install -r requirements.txt`
6. **Start Command** में डालें: `gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --threads 4 --timeout 120`
7. **Instance Type** में `Free` चुनें।
8. **Environment Variables** सेक्शन में जाकर नीचे दी गई टेबल के अनुसार सभी वेरिएबल्स को भरें।
9. **Create Web Service** पर क्लिक करें। 

### 🔹 चरण 7: वेबहुक और URL सेट करें
1. Render डिप्लॉयमेंट सफल होने के बाद, आपको एक URL मिलेगा (जैसे: `https://your-app.onrender.com`)।
2. अपने ब्राउज़र में यह लिंक खोलें: `https://your-app.onrender.com/admin/set-webhook?key=YOUR_ADMIN_KEY` *(जब तक `{"ok": true}` न दिखे, पेज रिफ्रेश करें)*।
3. अब वापस **@BotFather** में जाएं -> `/myapps` -> अपना ऐप चुनें -> **Edit Web App URL** दबाएं -> अपना Render URL डालें: `https://your-app.onrender.com/miniapp`
4. **@BotFather** में `/setdomain` दबाकर अपना नया Render डोमेन सेट करें।

## 🔐 Environment Variables (पर्यावरण चर और उन्हें पाने का तरीका)

Render के **Environment** टैब में ये सभी वेरिएबल्स (Key-Value) डालें:

| Variable Name | इसकी वैल्यू क्या डालें? | यह कहाँ से और कैसे मिलेगा? |
| :--- | :--- | :--- |
| `BOT_TOKEN` | बॉट का टोकन | **@BotFather** में `/newbot` दबाने पर, या `/mybots` में जाकर API Token से मिलेगा। |
| `ADMIN_ID` | आपकी खुद की टेलीग्राम ID | टेलीग्राम पर **@userinfobot** को खोजें, उसे `/start` भेजें, वो आपको आपकी ID दे देगा (जैसे 123456789)। |
| `DEST_CHANNEL` | मुख्य चैनल की ID | अपने चैनल का कोई भी मैसेज **@userinfobot** या **@MissRose_bot** को फॉरवर्ड करें। आपको ID मिल जाएगी (जैसे `-100...`)। |
| `STORAGE_CHANNEL`| प्राइवेट चैनल की ID | ऊपर वाले तरीके से अपने प्राइवेट चैनल की ID निकालें (जैसे `-100...`)। |
| `PUBLIC_URL` | आपका Render URL | Render पर डिप्लॉय करने के बाद आपको जो लिंक मिलेगा (जैसे: `https://app-name.onrender.com`)। इसमें आखिर में `/` न लगाएं। |
| `ADMIN_KEY` | कोई भी सीक्रेट पासवर्ड | आप खुद बनाएं, जैसे: `mypassword123` (यह वेबहुक सेट करने के काम आएगा)। |
| `APP_SHORT_NAME` | मिनी ऐप का शॉर्ट नेम | **@BotFather** में `/newapp` के दौरान जो Short Name दिया था (जैसे: `Wach`)। |
| `BOT_USERNAME` | बॉट का यूज़रनेम | **@BotFather** में अपने बॉट का यूज़रनेम देखें (बिना `@` के, जैसे `my_video_bot`)। |
| `MONETAG_ZONE` | Monetag का Zone ID | [publishers.monetag.com](https://publishers.monetag.com) पर अकाउंट बनाएं -> Add App -> Create Zone -> वहाँ से ID कॉपी करें। |
| `ADSGRAM_BLOCK_ID`| Adsgram का Block ID | [partner.adsgram.ai](https://partner.adsgram.ai) पर जाएं -> Create Block -> Block ID कॉपी करें (जैसे: `int-12345`)। |
| `CHANNEL_LINK` | आपके चैनल का लिंक | अपने पब्लिक चैनल का लिंक (जैसे: `https://t.me/yourchannel`)। |
| `CHANNEL_NAME` | आपके चैनल का नाम | जो नाम मिनी ऐप में ऊपर दिखेगा (जैसे: `Super Tech Channel`)। |

## 🤖 कमांड्स की जानकारी (Commands Guide)

### एडमिन के लिए (Admin Only):
* `/start` - बॉट को शुरू करने के लिए। एडमिन को "ready hu boss..." रिप्लाई मिलेगा।
* `/sender` - किसी भी यूज़र को Sender बनाने के लिए। बॉट आपसे उसकी न्यूमेरिकल ID मांगेगा।
* `/senders` - सभी अप्रूव्ड सेंडर्स की लिस्ट देखने और 'Remove' बटन से रिमूव करने के लिए।
* `/broadcast` - सभी यूज़र्स को मैसेज भेजने के लिए (ON/OFF बटन के साथ)।

### सेंडर्स के लिए (Approved Senders):
* सेंडर्स सीधे बॉट को **Photo + Video** (एल्बम बनाकर) भेज सकते हैं। बॉट उसे चैनल में पोस्ट कर देगा।

### सामान्य यूज़र्स के लिए:
* वे बॉट पर आकर वीडियो देख सकते हैं और ऐड्स देखकर वीडियो डाउनलोड कर सकते हैं।

## ⚠️ महत्वपूर्ण बातें (Important Notes)
* **Free Tier Sleep**: Render का फ्री टियर 15 मिनट बाद सो जाता है। बॉट को एक्टिव रखने के लिए UptimeRobot जैसी सर्विस से `/health` URL को हर 5 मिनट में पिंग करें।
* **20MB Limit**: Telegram Bot API की लिमिट के कारण, इस सिस्टम में वीडियो डायरेक्ट स्ट्रीम नहीं होती, बल्कि `file_id` के ज़रिए बॉट के द्वारा डिलीवर की जाती है। 
* **Security**: बॉट को हमेशा चैनल्स में एडमिन बनाकर रखें, वरना बॉट चैनल में पोस्ट नहीं कर पाएगा।
